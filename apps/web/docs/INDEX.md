## ❓ FAQ

**Q: Do I need to know React?**  
A: Basic React knowledge helps. Start with [React Docs](https://react.dev) if new.

**Q: Can I use this with a backend?**  
A: Yes! See [API Integration](./API_INTEGRATION.md) guide.

**Q: How do I add a new page?**  
A: Create `src/app/your-page/page.tsx`. See [Getting Started](./GETTING_STARTED.md).

**Q: Can I change the design?**  
A: Yes, fully customizable. See [Customization Guide](./CUSTOMIZATION.md).

**Q: Which hosting is best?**  
A: Vercel is recommended for Next.js. See [Deployment Guide](./DEPLOYMENT.md).

**Q: How do I fix build errors?**  
A: Check [Troubleshooting](./TROUBLESHOOTING.md) guide.
