# Architecture Decision Records

One file per decision: `NNNN-kebab-case-title.md`, numbered sequentially from
`0001`. Never renumber or delete a record; supersede it with a new one and set
the old record's status to `Superseded by ADR-NNNN`.

Statuses: `Proposed` → `Accepted` | `Rejected`; later `Superseded by ADR-NNNN`.
A record stays `Proposed` until the approvals it lists are recorded in it.
